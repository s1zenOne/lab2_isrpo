# \## Общее описание решения

# 

# Проект реализует набор функций для вычисления \*\*площади\*\* и \*\*периметра\*\* простых геометрических фигур: круга, квадрата, треугольника и прямоугольника.  

# Каждая фигура вынесена в отдельный модуль, содержащий функции для расчёта площади и периметра (или длины окружности).  

# Функции принимают числовые параметры и возвращают результат вычислений в виде числа с плавающей точкой.

# 

# ---

# 

# \## Модуль `circle.py`

# 

# \### Функция `area(r)`

# \*\*Назначение:\*\* Вычисляет площадь круга по радиусу.  

# \*\*Формула:\*\* `S = π \* r²`

# 

# \*\*Параметры:\*\*

# \- `r (float)` — радиус круга  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from circle import area

# >>> area(5)

# 78.53981633974483

# ```

# 

# ---

# 

# \### Функция `perimeter(r)`

# \*\*Назначение:\*\* Вычисляет длину окружности по радиусу.  

# \*\*Формула:\*\* `L = 2 \* π \* r`

# 

# \*\*Параметры:\*\*

# \- `r (float)` — радиус круга  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from circle import perimeter

# >>> perimeter(5)

# 31.41592653589793

# ```

# 

# ---

# 

# \## Модуль `square.py`

# 

# \### Функция `area(a)`

# \*\*Назначение:\*\* Вычисляет площадь квадрата по длине стороны.  

# \*\*Формула:\*\* `S = a²`

# 

# \*\*Параметры:\*\*

# \- `a (float)` — длина стороны квадрата  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from square import area

# >>> area(4)

# 16

# ```

# 

# ---

# 

# \### Функция `perimeter(a)`

# \*\*Назначение:\*\* Вычисляет периметр квадрата по длине стороны.  

# \*\*Формула:\*\* `P = 4 \* a`

# 

# \*\*Параметры:\*\*

# \- `a (float)` — длина стороны квадрата  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from square import perimeter

# >>> perimeter(4)

# 16

# ```

# 

# ---

# 

# \## Модуль `triangle.py`

# 

# \### Функция `area(a, h)`

# \*\*Назначение:\*\* Вычисляет площадь треугольника по основанию и высоте.  

# \*\*Формула:\*\* `S = (a \* h) / 2`

# 

# \*\*Параметры:\*\*

# \- `a (float)` — длина основания  

# \- `h (float)` — высота, проведённая к основанию  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from triangle import area

# >>> area(6, 4)

# 12.0

# ```

# 

# ---

# 

# \### Функция `perimeter(a, b, c)`

# \*\*Назначение:\*\* Вычисляет периметр треугольника по трём сторонам.  

# \*\*Формула:\*\* `P = a + b + c`

# 

# \*\*Параметры:\*\*

# \- `a (float)` — первая сторона  

# \- `b (float)` — вторая сторона  

# \- `c (float)` — третья сторона  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from triangle import perimeter

# >>> perimeter(3, 4, 5)

# 12

# ```

# 

# ---

# 

# \## Модуль `rectangle.py`

# 

# \### Функция `area(a, b)`

# \*\*Назначение:\*\* Вычисляет площадь прямоугольника по длине и ширине.  

# \*\*Формула:\*\* `S = a \* b`

# 

# \*\*Параметры:\*\*

# \- `a (float)` — длина прямоугольника  

# \- `b (float)` — ширина прямоугольника  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from rectangle import area

# >>> area(5, 3)

# 15

# ```

# 

# ---

# 

# \### Функция `perimeter(a, b)`

# \*\*Назначение:\*\* Вычисляет периметр прямоугольника по длине и ширине.  

# \*\*Формула:\*\* `P = 2 \* (a + b)`

# 

# \*\*Параметры:\*\*

# \- `a (float)` — длина прямоугольника  

# \- `b (float)` — ширина прямоугольника  

# 

# \*\*Пример вызова:\*\*

# ```python

# >>> from rectangle import perimeter

# >>> perimeter(5, 3)

# 16

# ```
