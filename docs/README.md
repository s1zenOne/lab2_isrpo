# Документация по проекту

## 1. Общее описание решения
Проект реализует набор функций для вычисления площади и периметра простых геометрических фигур: круга, квадрата, треугольника и прямоугольника.

Каждая фигура вынесена в отдельный модуль, который содержит две функции:

- `area(...)` — вычисление площади
- `perimeter(...)` — вычисление периметра (или длины окружности)

Функции принимают числовые параметры (`float`) и возвращают результат вычислений в виде числа с плавающей точкой.

---

## 2. Модули проекта

### 🔵 Модуль `circle.py`

#### `area(r)`
Вычисляет площадь круга.  
Формула: **S = π · r²**

Параметры:
- `r (float)` — радиус круга

#### `perimeter(r)`
Вычисляет длину окружности.  
Формула: **L = 2 · π · r**

---

### 🟥 Модуль `square.py`

#### `area(a)`
Вычисляет площадь квадрата.  
Формула: **S = a²**

Параметры:
- `a (float)` — длина стороны

#### `perimeter(a)`
Вычисляет периметр квадрата.  
Формула: **P = 4 · a**

---

### 🔺 Модуль `triangle.py`

#### `area(a, h)`
Вычисляет площадь треугольника.  
Формула: **S = (a · h) / 2**

Параметры:
- `a (float)` — основание
- `h (float)` — высота

#### `perimeter(a, b, c)`
Вычисляет периметр треугольника.  
Формула: **P = a + b + c**

Параметры:
- `a, b, c (float)` — стороны треугольника

---

### 🟩 Модуль `rectangle.py`

#### `area(a, b)`
Вычисляет площадь прямоугольника.  
Формула: **S = a · b**

Параметры:
- `a (float)` — длина
- `b (float)` — ширина

#### `perimeter(a, b)`
Вычисляет периметр прямоугольника.  
Формула: **P = 2 · (a + b)**

## 3. Описание тестируемого продукта
Тестируемый продукт включает модули:

- `circle.py`
- `square.py`
- `triangle.py`
- `rectangle.py`

Каждый модуль содержит функции для вычисления площади и периметра.  
Задача тестирования — проверить корректность работы всех функций на нулевых и положительных аргументах.

---

## 4. Стратегия тестирования

### Методология
Используется **модульное тестирование (unit testing)** с применением стандартного модуля `unittest`.

### Особенности тестирования
- Для каждой фигуры — отдельный тестовый файл.
- Один класс тестирования отвечает за один модуль.
- Используемые методы проверки:
    - `assertEqual` — для точных сравнений
    - `assertAlmostEqual` — для вычислений с использованием π

### Структура тестов
Тесты расположены в директории:

```
tests/
```

Файлы тестов:

```
tests/test_circle.py
tests/test_square.py
tests/test_triangle.py
tests/test_rectangle.py
```

---

## 5. Запуск тестов

### Запуск всех тестов:
```bash
python -m unittest discover -s tests
```

### Запуск одного тестового файла:
```bash
python -m unittest tests/test_circle.py
```
